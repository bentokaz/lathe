# Lathe

A music-making app (DAW) that runs in the browser. No install, no build step.

**Open it:** https://bentokaz.github.io/lathe/

- Timeline with synth, drum and audio tracks; clips you can move, trim, split and copy
- Piano roll with chord stamping, hover-to-chord, arpeggiate and velocity
- On-screen keyboard with chord pads and an arpeggiator; typing keyboard and MIDI input
- 150+ sounds: built-in synths, drum kits, layered indie sounds and the 128 General MIDI instruments (downloaded on first use)
- Styles that set key, tempo and instruments for a genre and mark the notes and chords that fit
- Mixer with EQ, drive, compressor, chorus, delay and reverb
- Record notes or microphone audio, import audio files, export WAV
- Video scoring: add a video, line music up with markers, export the video with your music
- Step-by-step tutorial (gear menu)

## Run it locally

Double-click `index.html`, or start the small server and open http://localhost:5173:

```
node serve.js
```

On Windows, `Start Lathe.bat` does both.

Projects autosave in your browser. Use **File, Save** to keep a project file.
